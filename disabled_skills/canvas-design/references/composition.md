# Composition and typography

Read this when developing a new static composition or revising its visual language.

## Visual direction

Use the user's brief and any chosen design philosophy as the foundation. A single-page PDF or PNG is the default unless more pages are requested. Original abstract work can use repeated marks, precise geometry, layered patterns, analytical reference markers, and a limited palette to make an invisible subject feel observable. These are techniques to select for the brief, not a required style for every poster.

Text can be quiet labels or a strong typographic gesture: a punk venue poster and a minimalist ceramics identity need different treatments. Preserve all required words. Match size and weight to hierarchy and readability, and keep intended content within the canvas and margins. Deliberate overlap may serve a composition; accidental collisions or clipped text fail review.

## Fonts

Inspect the bundled [canvas-fonts](../canvas-fonts) directory for typefaces and their license files. Choose a coherent pairing when contrast in hierarchy helps; a single suitable family is also valid. Check glyph coverage, including the requested language, and verify the rendered output uses the expected font or a readable fallback. Respect an existing brand's typography. Additional fonts require a compatible license and an allowed source; do not install or download them merely to create variety.

## Review and refinement

Inspect the exported PDF or PNG at the intended size. Check required text, margins, alignment, spacing, contrast, glyphs, resolution, and unwanted overlaps. For PDF, verify every delivered page. Refine the specific problem found; often spacing or simplification improves cohesion more than adding another graphic. Repeat affected checks after corrections. No second redesign is required when the output already satisfies the brief and these checks.

## Multiple pages

Create additional pages only when requested. Keep a common palette and conceptual language while giving each page a distinct composition. Bundle pages in one PDF or deliver clearly named PNG files. Check completeness, page order, and consistent visual hierarchy.
