# SESSION_RESUME.md 格式

- 當前任務：使用者目標、批准範圍與必要限制。
- 已完成／待辦：可比對的任務清單；只有項目可比較且分母明確時才給完成百分比，否則列已完成數／總數或直接列狀態。
- 中斷位置：實際檔案、函數、行號或最小可重現問題；行號未知則用穩定識別碼，不編造。
- 驗證：已執行指令與結果；區分原有失敗、本次回歸及未執行項目。
- Git／復原：repository、分支、已提交基線 hash、尚未提交／暫存檔案清單、備份位置。敏感值只記變數或位置，不寫 token、密碼或憑證内容。
- 環境：觀察到的 Python／uv／必要服務或資料路徑；沒檢查 GPU 狀態就不填猜測結果。
- 下次啟動：可直接續作的指令或短提示，包含先讀本文件、確認 Git 狀態，再處理哪個待辦。

替換既有快照前備份；保存後讀回，核對未提交內容有原工作檔／可恢復副本，不能只依賴舊 commit。恢復時先查看狀態與備份，不把 checkout／reset 當作讀取快照的必要步驟。
