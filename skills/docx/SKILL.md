# Word 文件處理

既有文件先確認用途與修改範圍，保留原檔或可恢復版本。單純讀取文字不需要完整編輯流程；若環境已有指定的文件工具，遵循其必要渲染規則。

| 工作 | 需要讀取的參考 |
| --- | --- |
| 用 docx-js 建立新文件 | [docx-js.md](docx-js.md) |
| 修改 OOXML、修訂追蹤、註釋與 Document API | [ooxml.md](ooxml.md) |
| 解包、驗證、打包 | [unpack.py](ooxml/scripts/unpack.py)、[validate.py](ooxml/scripts/validate.py)、[pack.py](ooxml/scripts/pack.py) |

先用現有頁面大小、樣式、表格及節設定；新文件依用途設計，保留分頁、目錄、超連結和腳註等必要結構。修改修訂時明確傳入作者，保留其他人的修訂；不靠全域替換作者名稱完成工具遷移。

交付前檢查 ZIP/XML 結構、關聯、需求內容與樣式。追蹤修訂需用原始文件作比較；渲染後檢查所有受影響頁面的截斷、表格與分頁，必要時擴大到整份文件。XML 閉合不等於 Word 可正常顯示。

修正發現的問題並重做相關檢查。若缺渲染器或 Word，回報實際完成的結構／內容檢查和未驗證相容性。只有比對證據支持時才說「已保留原始樣式」，不用固定成功措辭。

以繁體中文回報；使用者指定其他語言時依其要求。
