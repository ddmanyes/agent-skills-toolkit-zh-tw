# 審閱記錄模板

多主張或跨頁修訂時，將此格式複製到任務既有目錄；短稿可用同欄位直接回覆。不要覆寫此skill模板。

- 稿件版本／讀者／用途／授權範圍：
- 審閱者：自我覆核／獨立AI／外部專家；是否參與寫作或繼承對話：
- 實際讀完的正文、圖說、節點／轉接；未讀範圍：
- 實際看過的圖、表、報告及版本；未取得來源：
- 首次閱讀後，用自己的話重述主要結論：

| 主張位置／原句 | 資料與選入規則 | 對象／時間／基線／範圍 | 量測／分子／分母／尺度／公式 | 來源及版本 | 反例／未知／適用界線 | 判定 |
|---|---|---|---|---|---|---|
| | | | | | | 已核對／需修正／未驗證 |

每項適用的審閱規準均有紀錄；不適用寫理由。未知欄保留UNKNOWN及影響，不猜樣本數、日期、身分或功能證據。

| 問題ID | 結論／理解／文風 | 位置與原句 | 理由與來源 | 建議改寫 | 實際修訂位置 | 回讀／複審 |
|---|---|---|---|---|---|---|
| | | | | | 正文／圖說／地圖／索引 | resolved／unresolved |

## 完成範圍

- 自動／算術檢查：命令或人工替代方式、版本、範圍、結果。表格加總另核對原文是否用了正確範圍。
- 來源／語義審閱：適用規準、未解問題、影響及恢復條件。
- 網頁／視覺驗收：操作與實看截圖／原圖；未做項目明列。
- 舊版保留與資料完整性：
- 是否實際重跑分析：依授權據實記錄，不把閱讀既有表格誤稱新分析。
- 外部同步或發布：只記實際成功動作及回讀，未授權不執行。
