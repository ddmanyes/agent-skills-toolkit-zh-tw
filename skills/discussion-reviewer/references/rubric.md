# 審閱規準

逐項審查本輪修改範圍，回報問題位置、原句、來源與可採用改寫。每項可判「已核對」「需修正」「不適用（附理由）」或「未驗證（附缺少資料與影響）」。不要為滿足清單捏造問題或補未知值。

## 語句與文法

- 主詞、指代及時間是否明確？首段交代研究對象、物種或受試群體、處理、基線與取樣範圍。縮寫第一次出現時解釋；只重複縮寫不算定義。
- 每段是否有可重述的主旨？拆開混合多種估計或證據層級的長句。保留程度、否定、時序及因果限定，不以固定字數或AI偵測分數衡量。
- 定義放在當段首次使用處；術語表可補充，但不能替代單圖入口或單一節點的解釋。

## 數字與量測

| 檢查 | 需要在來源與稿件中對準的內容 |
|---|---|
| 合計／子群 | 每個數字的範圍、單位、來源列；分日、分組與總計分開。不要把單一子群數寫成全體。 |
| 原始量／衍生量 | 原始計數、正規化比例、差值、倍數、對數比各自命名。寫分子、分母、基準、轉換及零值意義；合併資料後的比例不等於原始總量。 |
| 多面板圖 | 各面板所測量、尺度、分母與資料範圍分開；其他結果表的方向支持不能說成眼前圖已展示。 |
| 可評估狀態 | 釐清檢查階段。列可評估者的具體比較與主要失敗原因；某階段未能評估，不等於其他檢查也失敗或生物作用不存在。 |
| 空間測量 | 起點、終點、位置代理、自配對、距離、背景母群、配對條件及上下界。網格中心不是解剖邊界，高於背景中位數不等於超過背景上界。 |
| 後選與回看 | 基因或事件在哪個時間點選出；未定、低計數、未變等是否保留分母。事後回看不是獨立驗證，也不是實際起始時間。 |
| 當日份額／跨期增量 | 同一時間點的分配份額不能當作增加部分的來源。公開子集、全組織與局部選區不可默認相同。 |
| 相對分數 | 目標與對照的計算、轉換、可計分條件分開。對照下降可使相減分數上升；個別正向基因不等於整組平均上升。 |
| 選入流程 | 初始候選→深度或品質限制→分類是否合格→最終物件；每個保留率各標分母。換分類與分類內選入都可能改變量級。 |
| 重現與單位 | 說明重現的是哪個量、哪些設定。紀錄、格網、細胞物件、視野、區域與技術抽樣不增加生物重複數；位置一致不證明細胞身分或邊界正確。 |
| 公式與識別碼 | 先定義變數，再說公式尺度及截斷。機器ID、程式碼、連結與公式變數不隨自然語言批次替換。 |

## 證據與推論

- 比較前對準物種、資料來源、日別、區室、樣本配對、批次、選入規則及生物n。即使同一基因，不同分類的基線比值與共同檢出率也不是同一估計。
- RNA、受體共同檢出、蛋白／分泌、訊號活化及功能因果分層；空間接近不證明細胞移動或訊號傳遞。未顯著不等於等效，低覆蓋或未能評估不等於陰性。
- 樣本、訪次、分類或日期尚未確認時，限制須在每個引用該結果的圖說就近可見。歷史「已驗證」類標籤不自動成為現行功能結論。
- 跨資料支持須列各自測項、分母及具體來源。未取得來源時限縮主張或標未驗證，不用「部分支持」代替核對。
- 分析前規則與事後敏感度分開。未重跑不等於可忽略既有方法修正；新舊區域和方法同時改變時，不將差異全歸因單一修正。
- 少數標記不能代表整套功能集合；視覺分布不同不能證明非隨機；樣本或設定數多不能當作同樣多的獨立驗證。

## 主稿、證據頁與探索地圖

- 每節回答具體問題；影響結論的反例和限制留在主稿，完整表與方法可展開或連證據。
- 單張圖必須可獨立讀懂對象、比較、量測、分母、尺度與限制。圖內舊旗標須實際檢視並就地解釋；來源連結存在不證明支持原句。
- 每個節點說明為什麼做、結果留下或撤回哪個解釋、不能回答什麼、缺哪份資料及拿到後回哪一步。詳情首段介紹本步，不重複不相干的分支導言。
- 節點各自界定資料範圍；設定總數不可套用相鄰節點的背景。箭頭標追問、回查或資料依賴，不畫成已證明生物因果或已完成工作。
- 內部樣本對照、外部資料身分與功能證據分開補件。未確認資料存在時寫「若取得」；只整理設定狀態的圖不直接證明樣本或蛋白限制。
- 修訂後核對正文、圖說、圖內標籤、索引及地圖；舊版保留要求與未解狀態延續。
