# 試算表處理

先定位指定範圍、用途與輸出；既有工作簿先清點工作表（含隱藏頁）、表頭、公式、命名範圍和重要格式，再抽樣內容。前 20 行可作起點，但不能代表全部結構。

- 保留原檔／可恢復副本；只改指定範圍，保留公式、隱藏頁、樣式與工作簿關聯。
- 明確資料型別、單位與空值規則；公式使用可檢查的依賴，避免循環與硬編碼計算結果。
- 需要重算時使用 [recalc.py](recalc.py)，先確認其 LibreOffice 依賴；缺少引擎則記錄未重算，不把舊快取當成新結果。
- 驗證代表性輸入、獨立預期值與跨表公式；核對公式錯誤、總計、資料筆數及受影響的格式。重新開檔檢查修改範圍與保留項目。
- 有視覺版面要求時渲染或預覽受影響範圍，修復截斷、重疊及不可讀數字格式。

完成時說明改動、實際重算／驗證結果及輸出位置。只有在相應應用中測過，才宣稱 Windows Office、Numbers 或其他客戶端相容；未測部分明確列出。

以繁體中文回報；使用者指定其他語言時依其要求。
