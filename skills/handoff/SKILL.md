# 任務交接

根據指定任務與下一輪目標整理交接。沒有指定時使用目前對話；不掃描無關私人聊天。

1. 記錄原始目標、範圍、使用者更正、既有批准與未批准動作。
2. 記錄工作目錄、分支與 SHA（適用時）、未提交修改、有效計畫與產物路徑；引用已有檔案，避免複製整份規格。
3. 列出已完成工作及驗證命令／結果，保留 FAIL、NOT_RUN、UNKNOWN、阻塞與失敗嘗試。
4. 寫出可直接接續的下一步、前置條件與完成條件；不要把待驗證推論當成事實。
5. 只推薦實際可用且與下一步有關的 skills；區分建議與已執行。遮蔽憑證和非必要個人資訊。

沿用專案交接位置；無慣例時存到 `~/LocalWork/Codex/` 下本任務目錄，使用帶日期或任務識別碼的檔名避免覆蓋。寫入後讀回檢查路徑與未完成項目，回報完整路徑。交接文件不是長期記憶更新，也不授權向另一聊天傳訊或建立新聊天。
