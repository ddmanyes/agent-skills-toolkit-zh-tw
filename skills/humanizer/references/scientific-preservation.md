# 科學內容核對

改寫前後對照：
- 同一研究對象、模型、時間、區室、分析單位與配對關係。
- 數字、方向、單位、分母、尺度及比較基線不變；縮寫首次定義。
- 生物n與library、細胞、bin、ROI、技術抽樣分開。
- RNA、受體共偵測、蛋白、分泌、訊號活化及功能介入分層。
- 未知、低覆蓋、無共同背景、HOLD不能換成零、陰性或通過。
- 事前規則、事後敏感度、原文實驗與本次分析分開。
- 相反結果與會改變主張的限制保留；表格移到證據頁仍需可回查。
- 引文與結果對應，來源缺口不靠流暢語句填補。

例（合成資料）：相對分數上升0.02，target不變而control下降0.02，可寫「分數上升來自control下降」；不可改成「訊號活化增強」。
如有最新證據要求更正舊結論，記錄修改依據；這是科學修正，不冒稱單純文風潤飾。
