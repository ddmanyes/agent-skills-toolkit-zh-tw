# 開發工作回顧

預設檢查目前任務；使用者指定其他紀錄時只讀相關範圍。此技能先提出建議，使用者同時要求修正時才在該範圍執行。

- 導覽：尋找檔案的困難是否來自缺少入口、錯誤路徑或依賴不明？優先修正既有導覽。
- 自動檢查：先查現有 lint、typecheck、測試及 CI，區分缺少檢查、未接線、失效與未執行。可機械判定的規則優先交給現有工具，不用長提示詞代替。
- 規範：需跨檔判斷的準則才留在文件。保留安全與授權邊界，不因提示詞長就刪除。
- 工具與資訊：從實際錯誤、等待與重複呼叫找改善，不能在沒有量測時宣稱速度或成本提升。
- 內容配置：優先更新已有文件，讓入口指向細節；不自動把單次事件變成全域限制。

每個候選附證據、造成的影響、建議修改、驗證方式及優先順序。區分已確認原因與假設；沒有足夠證據就說明缺口。若授權修改，保留原本使用者內容，執行對應驗證再記錄完成。個人記憶更新須有使用者直接要求，不由回顧自動觸發。
