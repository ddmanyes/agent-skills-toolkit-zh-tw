# 子代理開發

先確認目前環境實際提供的子代理工具與授權。任務跨檔案或有多個步驟，本身不代表需要委派；緊密相依、極小或需要同時修改同一檔案的工作可留在主線。

適合委派的工作包括獨立模組、具體範圍的程式探索、不同資料來源的查核及獨立審查。每次分派一個可完成、可驗收的界限。

1. 說明範圍、輸入資源、輸出、檔案所有權、依賴、驗收與失敗處理，以及適用的安全／權限限制。提供足夠背景，不能為減少 context 而讓 Sol、Luna 或其他支援模型缺少必要資訊。
2. 主代理同時推進不依賴該結果的實質工作；相依任務等必要結果再開始。共用工作樹時避免交叉覆寫，及時通知範圍變更。
3. 子代理依產物執行相應驗證：程式用相關測試，文件查引用與語意，唯讀探索提供可追溯證據。未測部分明確標示，不強迫每份產物都新增單元測試。
4. 主代理審查輸出、整合差異並完成必要整體檢查；子代理說完成不等於已整合。發現問題可在原授權範圍分派修正；工具不可用時主代理接續可完成的工作並說明限制。

以繁體中文回報委派結果、整合驗證和剩餘事項。此 Skill 不增加發布、外部通訊、憑證或檔案操作權限；metadata 中工具名稱供支援的客戶端使用，實際能力以目前工具清單為準。
