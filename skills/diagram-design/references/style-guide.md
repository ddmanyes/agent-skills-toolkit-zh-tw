# 視覺風格指南

## 版面

- 使用 4、8 或 16 px 的間距網格。
- 主要流程維持單一閱讀方向。
- 群組只用來表達真實邊界；不要把每個節點都放進框。
- 在節點、標籤與邊界之間保留至少 12 px 空間。
- 連線轉角使用一致半徑；同一張圖不要混用多種曲線語言。

## 文字

- 標題：Instrument Serif 或合適的品牌標題字體。
- 節點名稱：Geist／系統無襯線，14–18 px、500–600 weight。
- 標籤與狀態：Geist Mono／等寬字體，8–12 px。
- 長句改成短語；節點說明盡量不超過一行。
- 英文全大寫只用於很短的分類或狀態標籤。

## 色彩

預設色票：

| 角色 | 色彩 |
|---|---|
| 紙張背景 | `#f5f5f5` |
| 主文字／執行系統 | `#2d3142` |
| 次要文字／一般關係 | `#4f5d75` |
| 弱化元素 | `#7a8399` |
| 焦點能力 | `#eb6c36` |
| 動作／交付 | `#2e5aa8` |

焦點色面積應小於整張圖約 15%。不要用顏色作為唯一語意；同時使用標籤、線型或圖例。

## 連線

- 主要路徑：1.4–2 px 實線。
- 次要路徑：1–1.4 px。
- 可選影響或回饋：虛線。
- 箭頭使用 SVG marker；箭頭應停在節點邊界，不能穿入節點文字。
- 連線標籤放在開放區域，必要時加背景遮罩。

## 節制原則

- 不使用裝飾性漸層、3D、過度陰影或無意義光暈。
- 一張圖最多一種主要節點形狀；例外形狀必須代表例外語意。
- 圖例只解釋無法由內容本身推導的編碼。
