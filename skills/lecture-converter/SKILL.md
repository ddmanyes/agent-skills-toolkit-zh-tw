# 教學講義轉換

先界定來源與指定章節。完整轉換要讀完指定範圍，包括圖表、備註及程式碼；文字提取不足時使用實際可用的 PDF／PPTX 渲染工具，不能假設 view_file 能讀所有格式。若使用者只要摘要或局部修正，以其範圍為準。

1. 建立章節與來源頁碼對照，記錄定義、替代模型、公式、範例、重要標記及無法辨識處。
2. 按 [教學與格式規格](references/teaching-format.md) 重寫。完整保留來源知識及案例；將來源內容、推論、教學補充分清楚。不要補造歷史、數據或考試必考承諾。
3. 對照來源逐章檢查：正式／非正式定義、所有跨語言程式碼、數據表、案例規則、基數與參與約束都已覆蓋，並解釋其用途與限制。
4. 預設另存講義。使用者要求取代原 Markdown 時，先保留可恢復副本再覆寫；PDF／PPTX 原檔保留。已有有效備份就重用，無需每步重複確認。
5. 檢查 Markdown 結構、公式／程式碼、表格和實際使用的 Mermaid 渲染；修正後再交付。來源缺頁、OCR 不清或無法渲染時，標示位置及未驗證項目，不宣稱完整。

完成條件是指定範圍每章都有來源對照，保留全部實質知識點，教學補充有依據，輸出可讀。回報檔案位置、已完成章節、主要補充及限制。
