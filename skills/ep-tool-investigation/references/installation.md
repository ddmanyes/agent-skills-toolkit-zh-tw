# 安裝與依賴

此技能不包含 REA 執行環境，也不自動連接 EP、Second Brain 或 lcdda。

從 [Agent Skills Toolkit](https://github.com/ddmanyes/agent-skills-toolkit-zh-tw) 同步完整 `ep-tool-investigation` 與 `reverse-engineer-anything` 目錄，再按 [REA 跨機安裝指南](https://github.com/ddmanyes/agent-skills-toolkit-zh-tw/blob/main/docs/rea-installation.md) 安裝固定版本 runtime、為當前客戶端規劃 MCP 設定並驗證。不要複製另一台電腦的 config、金鑰或絕對路徑。

REA MCP 缺席時可繼續公開原始碼研究；不可將 skill 可見等同工具已連接。EP、SB 或 lcdda 缺席時標明相應檢查或同步未完成。不要因工具缺席擴大到私人資料外送或修改其他客戶端。原生 provider 依具體目標另裝，安裝 skill 本身不授權安裝付費工具或啟動待分析應用。
