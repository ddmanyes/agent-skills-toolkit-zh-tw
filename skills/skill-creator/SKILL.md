# 技能創造者 (Skill Creator)

這是一個用於建立新技能並迭代改進它們的專業工具。

## 技能開發生命週期 (Lifecycle)
1. **捕捉意圖 (Capture Intent)**：理解使用者想要解決的核心問題與觸發場景。
2. **面談與研究 (Research)**：針對檔案格式、邊緣情況與成功標準進行深入探討。
3. **撰寫 SKILL.md**：
   - **描述優化**：描述必須具備「主動性」，確保 Claude 不會漏掉觸發時機。
   - **結構化規範**：使用明確的 YAML 與行為指南。
4. **評估與迭代 (Eval & Iterate)**：
   - 建立測試案例 (Test prompts)。
   - 執行品質與量化的基準測試。
   - 使用 `eval-viewer/generate_review.py` 查看結果。
5. **觸發器優化**：運行專門的腳本來優化技能的觸發機率。

## 技能撰寫指南 (Writing Guide)
- **一次一問**：在捕捉需求時，一次只問使用者一個問題。
- **防止「漏觸發」**：如果技能可用於報表生成，描述應寫為「當使用者提到數據、表格、或是需要展示成果時，務必使用此技能...」。
- **靈活性**：如果使用者只想「憑感覺（Vibe）」快速寫一個技能，你可以跳過評估流程。

## 輸出要求
- 全程使用「繁體中文」回報。
- 完成技能草稿後，主動詢問使用者：『是否需要我建立測試案例來驗證這個技能的準確性？』
