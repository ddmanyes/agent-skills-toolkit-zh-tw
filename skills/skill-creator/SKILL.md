# 工具包 Skill 維護
保留舊名稱供明確呼叫相容。選擇本工具包是因為需要其跨客戶端規範或既有腳本，不因普通任務提到數據、文件或程式碼而啟用。

1. 確認真正能力、應觸發及不應觸發的相近請求、完成條件、目標客戶端。已清楚的需求不重複訪談。
2. 保留必要知識、安全、權限、識別碼、數值與恢復條件；先辨認正本、別名與分發副本。
3. 入口寫共同目的、必要限制與操作分支。詳細範例、格式與流程放入需要時才讀的 references；簡單技能不用額外拆層。
4. 新建或封裝時重用 scripts/init_skill.py、scripts/package_skill.py；操作前查看其參數。已有 Skill 不重新初始化。
5. 使用 scripts/quick_validate.py 和可用的 skill-qa-gate 檢查。模型選擇效果以真實任務及相近負例評估；不存在的檢視器不作必需步驟。
6. 修復已授權範圍的問題後交付。行為驗證只在安全、可隔離的資源上執行；外部發布沿用使用者授權。

## 相容與驗收
- 分別保留 Astra、Sol、Luna 需要的語義與驗收，不以單一模型直覺判定規則無用。未做跨模型測試時明確標示。
- Codex 的明確手動啟用設定位於 agents/openai.yaml 的 policy.allow_implicit_invocation；其他客戶端欄位依其支援維護。不要因工具有副作用就擅自隱藏入口。
- 替換或移除前保留備份；檢查資料、指標與權限含义。只有實測通過才能宣稱相應能力已驗證，不聲稱未測的效能提升。
- [工作流程參考](references/workflows.md) 用於需要選擇多步驟流程時；[輸出模式](references/output-patterns.md) 用於設計具體交付格式時。
