# Course Video Note Template

依影片內容刪減或擴充，但保留來源、時間軸、限制與轉錄聲明。

```markdown
# <課程名稱>｜重點整理

- 來源：<URL 或本機路徑>
- 課程長度：<HH:MM:SS>
- 影片日期：<YYYY-MM-DD 或未知>
- 整理方式：<字幕／本機 STT／投影片校正>

## 30 秒總結

<用一段話交代主張、應用與限制。>

## 課程時間軸

| 時間 | 主題 | 一句話重點 |
|---|---|---|
| 00:00–00:00 | ... | ... |

## 核心概念

### 1. <主題>

- 定義或主張
- 講者案例
- 可回看時間碼

## 實務應用

- ...

## 風險與限制

1. **<風險>**：<影響與條件>

## 最值得帶走的重點

1. ...

## 複習清單

- [ ] ...

## 轉錄說明

逐字稿由自動語音辨識產生。<列出仍可能誤聽的語言、產品名或縮寫。>
```

## Second Brain 補充

建立 SB note 時，在正文最前方加入：

```markdown
## 來源與附件

- 課程頁：<URL>
- 本機影片：`<absolute-path>`
- 本機逐字稿：`<absolute-path>`
- 本機字幕：`<absolute-path>`
```

搜尋到同一來源 URL 的既有 note 時，先讀取原文。只有新增資訊才使用 append；需要重整時先完整讀取再 update。
