# 執行實作計畫
先讀指定計畫及適用指示；未指定時沿用 IMPLEMENTATION_PLAN.md 或 task_plan.md。若計畫缺少驗收，從已批准需求補足可檢查條件；改變重要決策或授權範圍時才回到使用者。

1. 鎖定下一個有條件可執行的未完成任務，標記進行中並實作。
2. 執行計畫列出的必要驗證。依輸出定位錯誤，修復本次變更造成的問題，再重跑受影響檢查。
3. 區分既有失敗、環境限制與新回歸。缺少必要資訊、需要額外權限或無法安全修復時，報告完成內容、證據與可恢復下一步。
4. 驗證成功後才更新狀態和日期，按專案慣例記入 execution_trace.md 或既有進度紀錄。
5. 已授權提交時檢查 staged diff，只提交本次相關檔案；否則保留工作樹。接續其餘任務，不在第一次實作後提前交付。

完成條件：批准範圍內的項目已完成、必要檢查已有結果、限制與剩餘事項清楚。繁體中文回報實質進度；不為每個安全重試重複索取批准。
